# 📇 Kartu Biodata & Business Card — Riko Londong

Kartu identitas dan kartu nama digital interaktif dengan estetika **Neumorphism (Soft UI)** yang modern, bersih, dan elegan.

Proyek ke-2 dalam rangkaian eksplorasi **100 Days of Code / VibeCode App Journey**.

---

## ✨ Fitur Utama

- **Desain Neumorphism (Soft UI)**:
  - Efek bayangan ganda (*dual-layer soft shadows*) yang memberikan kesan timbul dan elegan.
  - State interaktif (*pressed / inset shadow*) saat tombol atau kartu diklik.
  - Tipografi modern menggunakan **Plus Jakarta Sans** dari Google Fonts.
- **Dark Mode & Light Mode**:
  - Dukungan tema ganda yang mulus dengan tombol toggle di navigasi.
  - Pengaturan tema tersimpan otomatis di `localStorage`.
- **Interaktivitas & Kemudahan Berbagi**:
  - **Salin ke Papan Klip (Copy to Clipboard)**: Salin informasi data diri (Nama, Email, Telepon, Alamat) dengan satu klik disertai notifikasi umpan balik visual (*toast*).
  - **Unduh vCard (.vcf)**: Ekspor kontak langsung ke format vCard untuk disimpan ke buku kontak smartphone atau komputer.
  - **Tautan Sosial & Portfolio**: Akses cepat ke GitHub, LinkedIn, dan email profesional.
- **100% Responsif & Ringan**:
  - Desain adaptif untuk smartphone, tablet, maupun desktop.
  - Bebas dependensi eksternal berat (Zero runtime dependencies).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 Semantic**: Struktur semantik dengan aksesibilitas ramah pembaca layar (ARIA labels).
- **Modern Vanilla CSS**: Variabel tema (CSS Tokens), Neumorphic shadow matrix, flexbox & grid responsif.
- **Vanilla JavaScript (ES6+)**: Logika pergantian tema, Clipboard API, dan interaktivitas kartu.
- **Node.js**: HTTP Server lokal ringan untuk pengujian mandiri.

---

## 🚀 Cara Menjalankan Secara Lokal

1. **Jalankan server lokal bawaan**:
   ```bash
   node server.js
   ```
2. **Buka di browser**:
   Kunjungi [http://localhost:4173](http://localhost:4173) di browser Anda.
