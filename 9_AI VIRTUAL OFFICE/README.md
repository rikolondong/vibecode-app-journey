# 🏢 Proyek 9: AI Virtual Office 3D (Isometric Voxel Human Multi-Agent)

Aplikasi visualisasi dan simulasi interaktif **AI Virtual Office 3D Isometrik** dengan kru karakter manusia voxel bergaya modern tech-workspace (mengacu pada proporsi voxel art Crossy Road / Chibi 3D).

---

## 📸 Fitur Utama

- **Karakter Manusia Voxel 3D (Chibi Voxel Aesthetics)**:
  - **Bima (Lead Architect & Orchestrator)**: PM berjas smart-casual dengan kacamata, mengkoordinasikan blueprint proyek.
  - **Nadia (Research & Data Scientist)**: Peneliti bersanggul auburn/ginger dengan kacamata merah, meja penuh dokumen dan dual-display.
  - **Reza (Senior Coder)**: Programmer ber-hoodie merah dengan headphone gaming besar, coding di triple ultrawide monitor.
  - **Maya (QA & Security Sentinel)**: Auditor pirang kuncir dua yang menjalankan test suite, OWASP scans, dan inspeksi bug board.
  - **Hendro (DevOps & Memory Server)**: Teknisi berjenggot bertopi kupluk yang mengelola server rack kluster dan vector database.
- **Ruangan Kantor Realistis & Ergonomis**:
  - Lantai kayu parket oak & walnut, karpet beludru eksekutif, dan uap kopi mengepul dari mesin espresso.
  - Partisi kaca frosted, kursi putar kantor ergonomis, pot tanaman hias Monstera.
  - Rak server bertingkat dengan animasi lampu LED status yang berkedip.
- **Simulasi Multi-Agent Real-time**:
  - Pertukaran dokumen/dossier 3D melayang dengan jejak partikel (*glowing particle trail*).
  - Animasi mengetik pada keyboard meja secara otomatis saat agen sedang bekerja.
  - Sintesis audio Web Audio API (efek ketikan keyboard mekanik, dispatch blip, suara alert).
- **Misi Siap Pakai & Kustom**:
  - 🚀 *Deploy SaaS MVP*
  - 🛡️ *Security Vulnerability Audit*
  - 📊 *Riset Pasar & Tren AI 2026*
  - ⚡ *Emergency Production Hotfix*
  - *Custom Instruction Prompt Box* (Kirim instruksi langsung ke tim kantor).
- **Navigasi & Kontrol Kamera**:
  - Drag untuk rotasi/geser, scroll untuk zoom (40% - 240%).
  - Preset kamera cepat (*Overview, PM Desk, Dev Pod, Research Lab, Break Lounge*).
  - Inspector detail profil, thought chain, dan live code generator.

---

## 🛠️ Tech Stack

- **HTML5 Canvas 2D API** (Pure Procedural 3D Isometric & Depth-Sorted Voxel Engine)
- **Vanilla JavaScript (ES6+)**
- **Web Audio API** (Sintesis audio prosedural tanpa file audio eksternal)
- **Tailwind CSS** (Modern Glassmorphism HUD)

---

## 🚀 Cara Menjalankan

Cukup buka `index.html` langsung di browser modern mana saja tanpa instalasi dependency tambahan.
